# "What interrupts the loop"

Ereignisse, die außerplanmäßig einen Lauf auslösen. Reaktion jeweils: Orchestrator → zuständige Abteilung → Brief → Approval.

| Trigger | Zuständig | Standard-Reaktion |
|---|---|---|
| Search-Demand-Spike | research-intelligence | Content-Brief + schneller Artikel/Post |
| Wettbewerber veröffentlicht Content | research-intelligence | Gap-Analyse, Gegenbrief |
| Content-Kalender zu dünn | orchestrator | Backlog aus Signal-Log auffüllen |
| Ranking einer Seite fällt | analytics-optimization + content-engine | Refresh der Seite |
| Ein Post geht viral | distribution-publishing | Nachlegen: Follow-up, Newsletter-Erwähnung |
| Ad-Creative ermüdet | creative-studio | neue Varianten |
| Kommentar-/DM-Flut | distribution-publishing | Antwortvorlagen, Owner bei Randfällen |
| E-Mail-Öffnungsraten sinken | audience-email | Betreff-Tests, Listenhygiene |
| Ausgaben-Abweichung ("spend drop") | orchestrator | **immer an Owner** (Budget) |

Die genaue Beschriftung der letzten Zeile war im Video schwer lesbar; Eintrag ist best effort.
