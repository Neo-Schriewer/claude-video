# Tool-Stack und Startempfehlung

Die Original-Architektur nutzt ~30 Tools. Als Einzelperson zahlst du dafür schnell dreistellig pro Monat. Empfehlung:

**Phase 1 (nur das Nötige):** Claude Code, Buffer (oder ein Scheduler), ein Newsletter-Tool (Kit/beehiiv), GA4 oder Fathom, Canva.
**Phase 2 (bei Engpass):** Semrush/Ahrefs (SEO), ManyChat (DMs), ElevenLabs/Midjourney.
**Phase 3:** LangGraph + pgvector erst, wenn dateibasiertes Gedächtnis (`marketing-os/`) nicht mehr reicht.

Warum: LangGraph/pgvector bringen Wartungsaufwand, bevor du überhaupt weißt, welche Inhalte funktionieren.
